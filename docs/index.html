Smart Traffic Monitoring System

Deep Learning-Based Vehicle Detection and Traffic Density Analysis

About the Project

This project explores traffic monitoring using CCTV images and deep learning to identify vehicles and estimate traffic density.

Project Features

  • CCTV image-based traffic analysis
  • Vehicle detection and counting
  • Traffic density classification
  • Results visualization

Technology Stack

Python, Django, Deep Learning, HTML, CSS and JavaScript
